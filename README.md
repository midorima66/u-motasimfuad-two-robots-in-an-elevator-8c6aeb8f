# Two Robots in an Elevator

One funny line for the make.fun bounty
[u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f](https://make.fun/bounty/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f):
two robots, one elevator, and the small talk neither of them is built
for. The line:

> Nice weather we're having. My sensors cannot confirm this, but I enjoy saying it while we avoid eye contact we do not have.

## What is in this repo

- `main.py` — a small Python 3 script that writes the line to
  `/output/entry.txt` (UTF-8, no trailing newline), creating `/output`
  first if it does not exist yet.
- `LICENSE` — the licence for this entry.

## Running it

```sh
python3 main.py
```

After the run, `/output/entry.txt` holds exactly the line above:
123 characters, no trailing newline.
